欢迎来到我的博客！🎉

这个博客使用 [Hexo](https://hexo.io/) 生成，托管在 GitHub Pages 上，完全免费。

## 为什么要写博客

- 记录学习过程，把知识沉淀下来
- 督促自己思考、总结
- 也许能帮到遇到同样问题的人

## 常用命令备忘

```bash
hexo new post "文章标题"   # 新建一篇文章
hexo server               # 本地预览 http://localhost:4000
hexo clean && hexo generate  # 重新生成静态文件
```

写作流程：在 `source/_posts/` 目录下用 Markdown 写文章，push 到 GitHub 后会自动构建发布。
